# ⚖️ Trestní Dilemata ČR

> Interaktivní webová aplikace pro porovnávání závažnosti trestných činů na základě **Trestního zákoníku ČR (zákon č. 40/2009 Sb.)** a reálných **statistik soudního rozhodování v ČR** (Ministerstvo spravedlnosti ČR, JakTrestame.cz, ČSÚ).

🔗 **Živá verze na GitHub Pages:** [https://karelberka.github.io/trestni-dilemata/](https://karelberka.github.io/trestni-dilemata/)

---

## 🎯 Hlavní funkce

- **⚔️ Dilema & Duelová aréna**:
  - Prezentuje dvojici konkrétních modelových situací z různých oblastí práva.
  - Hlasování myší nebo klávesovými zkratkami (`← / 1` pro volbu vlevo, `→ / 2` pro volbu vpravo, `Mezerník` pro další).
  - **Okamžitá konfrontace se zákonem a soudní praxí**:
    - Zákonná sazba a citace paragrafu z trestního zákoníku ČR.
    - Reálné statistiky ukládaných trestů (podíl nepodmíněného vězení, podmínek, peněžitých trestů a průměrná délka trestu).
    - Věcný rozbor újmy pro oběť a dopadu na společnost.

- **🎯 Inteligentní Matchmaking (Gaussovský výběr)**:
  - Algoritmus páruje činy se srovnatelnou závažností / Elo hodnocením ($e^{-\frac{\Delta Elo^2}{2\sigma^2}}$).
  - Zabraňuje triviálním volbám (*Vražda vs. Krádež kola*) a generuje vyrovnaná morálně-právní dilemata.

- **📊 Žebříček činů (3 pohledy)**:
  - Podle hlasování veřejnosti (živý Elo rating).
  - Podle horní hranice trestní sazby v zákoníku.
  - Podle reálné praxe soudů (přísnost nepodmíněných trestů).

- **📖 Katalog zákoníku & Encyklopedie**:
  - Vyhledávání a filtrování podle kategorií (život a zdraví, majetek, hospodářské, svoboda a lidská důstojnost, veřejný pořádek, doprava a životní prostředí).

- **👤 Profil soudce**:
  - Sledování shody vašeho úsudku se zákonem a soudní praxí s vyhodnocením eticko-právního profilu.

- **☁️ Cloudová synchronizace (Supabase)**:
  - Plně statická aplikace běžící na GitHub Pages s možností asynchronního odesílání hlasů do PostgreSQL databáze (Supabase) a automatickým fallbackem na lokální úložiště (`localStorage`).

## 🚀 Spuštění a nasazení

### Lokální spuštění
Aplikace nevyžaduje žádný build ani instalaci balíčků. Stačí otevřít soubor `index.html` v libovolném moderním webovém prohlížeči.

### Nasazení na GitHub Pages
1. V repozitáři na GitHubu přejděte do **Settings** -> **Pages**.
2. V **Build and deployment** nastavte:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `/ (root)`
3. Během minuty je web dostupný na `https://<vase-jmeno>.github.io/trestni-dilemata/`.

## 🗄️ Konfigurace databáze (Supabase)

Pro centrální ukládání hlasů z celého internetu:
1. Založte bezplatný projekt na [supabase.com](https://supabase.com).
2. V **SQL Editoru** spusťte:
```sql
CREATE TABLE IF NOT EXISTS public.votes (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    winner_id TEXT NOT NULL,
    loser_id TEXT NOT NULL,
    session_id TEXT,
    created_at TIMESTAMPTZ DEFAULT timezone('utc'::text, now()) NOT NULL
);

ALTER TABLE public.votes ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Povolit vkládání hlasů všem" ON public.votes FOR INSERT TO anon WITH CHECK (true);
CREATE POLICY "Povolit čtení hlasů všem" ON public.votes FOR SELECT TO anon USING (true);
```
3. Zkontrolujte `supabaseUrl` a `supabaseAnonKey` v souboru `config.js`.
