# 🚀 Návod: Nasazení na GitHub Pages a ukládání hlasů do cloudu

Tento návod popisuje, jak aplikaci **Trestní Dilemata** publikovat online na **GitHub Pages** a jak jednoduše propojit bezplatnou cloudovou databázi pro ukládání voleb všech návštěvníků.

---

## Část 1: Nasazení na GitHub Pages (Zcela zdarma)

1. Vytvořte si na [GitHub.com](https://github.com) nový repozitář (např. `trestni-dilemata`).
2. Nahrajte do něj všechny soubory z této složky (`index.html`, `styles.css`, `app.js`, `crimes-data.js`, `config.js`).
3. V repozitáři na GitHubu otevřete **Settings** (Nastavení) -> v levém menu zvolte **Pages**.
4. V sekci **Build and deployment** vyberte:
   - Source: **Deploy from a branch**
   - Branch: `main` (nebo `master`) / složka `/ (root)`
5. Klikněte na **Save**. Během 1–2 minut bude vaše stránka dostupná na adrese `https://<vase-jmeno>.github.io/trestni-dilemata/`.

---

## Část 2: Ukládání voleb do centrální databáze (Supabase)

Aplikace funguje **ihned i bez databáze** (data se ukládají v prohlížeči každého uživatele do `localStorage`). Pokud však chcete sbírat hlasy od všech lidí z internetu a mít společný živý žebříček, doporučujeme **Supabase** (bezplatný PostgreSQL cloud):

### Krok 1: Založení projektu na Supabase
1. Zaregistrujte se zdarma na [supabase.com](https://supabase.com).
2. Vytvořte nový projekt (např. `trestnidilemata`). Zvolte heslo k databázi a region (např. *Central EU / Frankfurt*).

### Krok 2: Vytvoření tabulek v SQL Editoru
V administraci Supabase klikněte vlevo na **SQL Editor** -> **New query**, vložte následující SQL skript a klikněte na **Run**:

```sql
-- 1. Tabulka pro jednotlivé zaznamenané hlasy
CREATE TABLE IF NOT EXISTS public.votes (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    winner_id TEXT NOT NULL,
    loser_id TEXT NOT NULL,
    session_id TEXT,
    created_at TIMESTAMPTZ DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- 2. Povolení zápisu pro anonymní návštěvníky z webu
ALTER TABLE public.votes ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Povolit vkládání hlasů všem" 
ON public.votes FOR INSERT 
TO anon 
WITH CHECK (true);

CREATE POLICY "Povolit čtení hlasů všem" 
ON public.votes FOR SELECT 
TO anon 
USING (true);
```

### Krok 3: Vyplnění klíčů v `config.js`
1. V administraci Supabase přejděte do **Project Settings** -> **API**.
2. Zkopírujte:
   - **Project URL** (např. `https://abcdefgh.supabase.co`)
   - **anon / public key** (dlouhý token)
3. Otevřete v projektu soubor [config.js](file:///c:/Users/krapn/Dropbox/Antigravity/Tresty/config.js) a vložte hodnoty:

```javascript
window.TRESTY_CONFIG = {
  supabaseUrl: "https://vase-id-projektu.supabase.co",
  supabaseAnonKey: "vas-dlouhy-anon-public-klic...",
  matchmaking: {
    eloProximitySigma: 220,     // Čím menší, tím podobnější závažnost činů
    broadExplorationRate: 0.08  // 8% šance na širší náhodné srovnání
  }
};
```

4. Změny nahrajte (commitněte) na GitHub. Aplikace automaticky detekuje propojení a v horní liště se rozsvítí `🟢 Cloud synchronizován`.

## Část 3: Jak funguje chytrý matchmaking (párování)?

- Místo čistě náhodného losování používá aplikace **Gaussovský vážený výběr podle blízkosti závažnosti a Elo ratingu** ($e^{-\frac{\Delta Elo^2}{2\sigma^2}}$).
- Činy s podobnou závažností (např. *Zabití v afektu* vs. *Těžké ublížení na zdraví*, nebo *Zpronevěra* vs. *Daňový podvod*) jsou párovány přibližně v **85–90 % případů**.
- Vytváří se tím skutečně vyrovnaná, podnětná a statisticky hodnotná morálně-právní dilemata namísto zjevných duelů typu *Vražda vs. Krádež kola*.
